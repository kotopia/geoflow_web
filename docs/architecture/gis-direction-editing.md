# GIS 선택·심도·방향각 사용 흐름

2026-11-02 · Connector 1.4.8 구현. 배포 여부와 고정 산출물은 `docs/operations/qgis-plugin-stable-release.json` 및 해당 GitHub 게시 실행 결과로 확인한다.

## 계산·저장 계약

선택은 클릭/드래그를 한 도구에서 처리하며 Shift 추가, Ctrl 해제, Esc 취소를 지원한다. 다중 선택을 단일 객체로 축소하지 않는다. 심도는 기존 Survey/H 검색·계산·단위·정밀도를 재사용하며 지원 관리 레이어에서 2개 이상 선택하면 실행할 수 있다. 편집 버퍼는 적용 때 시작하고 서버 저장은 기존 명시적 저장 경로를 사용한다. 결과는 성공·실제 변경·동일·건너뜀·실패를 구분한다.

각도 좌표축은 사용자 확정 EPSG:5186, 동쪽 0°·북쪽 90°·반시계방향이다. `normalize(90-A)` 또는 `atan2(dy,dx)`를 사용한다. 미터 거리 검색용 AEQD 좌표와 구분하고 원본 버텍스를 EPSG:5186으로 직접 변환한다. 기존 SQL과 각도 기준은 같지만 시설과 가까운 실제 파트/선분을 사용하며 원래 버텍스 순서를 유지한다. 180° 반전은 사용자 조정이다. 내부 정밀도는 유지하고 실제 필드 타입/중앙 scale에 맞춰 HALF_UP 반올림 후 [0,360) 정규화한다. 기존 값의 자동 변환은 없다.

최근접 후보 중 최장 버텍스 간격, 동일 길이면 객체 UUID 순서를 사용한다. 같은 객체의 최종 순서는 레이어 UUID/파트/선분 순서로 고정한다. 명시적 중앙 레이어·필드 UUID만 기능 대상으로 삼고 일반 숫자 필드를 이름으로 추정하지 않는다. 중앙 capability가 빠진 구 응답만 이미 알려진 두 UUID 쌍을 호환 처리한다.

## 시설별 설정과 심볼

환경설정의 서버·프로젝트별 로컬 override에서 방향각 숫자 필드, 기준선 레이어, 허용거리와 선 위 일치 조건을 지정한다. 선 위 일치는 EPSG:5186 수치 허용오차 0.000001m이며 좌표를 이동시키지 않는다. 선택한 시설 구분 필드/저장 코드값 및 기준선별 관경 숫자 필드를 이용해 작은 관경 쪽을 계산할 수 있다. 관경 단위는 같아야 한다. 이 규칙은 서로 다른 관경을 가진 2개 이상 관로 접속이 필요하며 관경 누락·동률·불명확한 방향은 검토 대상으로 남긴다. 나머지 시설은 일반 최장 선분 규칙을 유지한다.

표시는 사용자가 확인한 기존 필드/표현식 연결을 보존한다. 누락된 연결과 이전 플러그인이 만든 CAD/지도 CRS 표현식만 중앙 저장 필드 연결로 교체한다. 심볼 보정은 표시 전용이다. 레이어 표시명으로 분기하지 않는다. 직접 회전은 실제 표시 규칙을 원본 객체/FID에서 해석한 3배 심볼을 드래그한다. ELSE는 형제 규칙의 실제 적용 여부에 따라 판정하며 원래 QGIS 렌더링과 비교한다. 취소는 운영 속성과 렌더러를 복구한다.

## 폼과 사용자 흐름

폼 배치와 코드 새로고침은 환경설정의 폼 탭에 있다. 레이어 선택으로 아직 열지 않은 폼도 배치할 수 있다. 메인 도구와 Survey는 Designer UI로 정의한다. 폼 상단에 이전값·근처값·심도·방향각 도구를 왼쪽 정렬하고, 탭 오른쪽에 카메라·저장을 둔다. 단일 방향각 계산 성공은 편집 버퍼에 바로 입력하며 실패는 결과창을 연다. 일괄 계산은 선택 적용을 유지하고 실패·검토만 보기 필터 및 행 위치 이동을 제공한다. 필터는 숨긴 성공 항목의 적용 선택을 바꾸지 않는다.

작업상태의 중앙 status 계약은 조회 시 NULL을 보존하고 명시적 저장 때만 미완료로 바꾼다. 완료는 스위치를 켰을 때만 저장하며 해제하면 미완료다. 기본 NULL은 회색, 미완료는 오렌지, 완료는 파란색이고 readonly/권한 검사를 유지한다. 표시만으로 dirty 또는 반복 저장 안내를 만들지 않는다. 첫 선택이 다중 선택이어도 탭 저장 버튼이 해당 레이어의 일괄 버퍼 변경을 기존 서버 저장 함수로 전달한다.

## 검증 경계

`services/direction_math.py`, `services/direction.py`, `ui/direction.py`가 계산·검증·미리보기를 공유한다. 실제 QGIS/Qt 임시 레이어에서 계산, ELSE 렌더링, 상태 저장/취소, 폼 배치, 사진 탭, 선택/권한, 서버 실패 버퍼 보존을 검증한다. 운영 프로젝트 서버 저장을 임시 레이어 시험으로 대체하여 성공했다고 보고하지 않는다. 중앙 DB/정의/시설 속성의 일괄 변경은 이 플러그인 게시에 포함하지 않는다.
