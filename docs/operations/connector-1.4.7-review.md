## 확인한 원인과 변경

이전 로컬 구현은 원점 변경이 새 저장값 및 기존 심볼 해석 양쪽에 영향을 주고, connected 종점은 안쪽 방향으로 반전했다. 검색용 AEQD 방향을 저장하는 경로와 계산 중 Python round로 정수화하는 경로도 있었다. 이번 운영 규칙은 EPSG:5186 좌표축의 동쪽 0°·반시계방향, 원래 버텍스 진행 방향으로 고정했다. 검색과 각도 좌표를 분리하고 실제 필드 타입/precision 및 중앙 scale에 맞춰 적용 직전 HALF_UP/360 정규화한다.

기존 SQL과 같은 마지막 선분 조건에서는 같은 좌표축/진행 방향을 사용한다. 신규는 시설과 접속한 실제 파트/선분을 고르며, 모호한 후보는 단일 선택/일괄 검토로 남긴다. 정수화 순서가 달라 .5 경계에서는 과거 double의 ties-to-even과 차이가 날 수 있다. A=89.5°에서 흔한 과거 결과 0°, 신규 결과 1° 사례를 검사했다. 운영 DB의 과거 SQL을 실행하지 않았다.

중앙 서버 설정/DB는 변경하지 않았다. 중앙 UUID·필드 매핑·거리·심볼 보정을 재사용하고, 로컬 설정의 시설별 기준선/반경 override를 유지한다. 플러그인 공통 해석만 승인된 east/counterclockwise 규칙으로 고정했다. 문자열 방향각 필드는 자동 숫자 변환하지 않으며 명시적으로 안내한다.

메인 아이콘은 Designer .ui가 소유한다. 필드 액션은 중앙 UUID를 따라 기존 폼에도 갱신된다. 수동 회전은 기준선 없이 동작하며, CAD 다이얼·숫자·지도 손잡이·지도 CRS 변환·심볼 보정이 같은 저장값을 사용한다. 자체 편집 버퍼를 외부 충돌로 오인해 반복하던 저장/취소 이동은 provider 원본 분리 및 guard 재진입 차단으로 수정했다.

## 검증

- QGIS 4.2.2 실제 엔진/Qt 회귀 프로그램 24개 통과. 계산기 단위 테스트만으로 대체하지 않았다.
- 방향성 임시 심볼의 8방향 실 렌더링 이미지: `release/1.4.7/cad-directions.png`. 동0/북90/서180/남270 및 대각선 방향을 확인했다.
- 자동·단일 후보 선택·일괄 검토, 시점/종점, 역순180, 중간 꺾임, 다중 접속, 2번째 파트, 중복/0길이/기준선 없음, mixed CRS, 실제 정수 타입과 precision, 경계 반올림, 복합 마커 상대각 유지, 반복 renderer 연결을 검사했다.
- 실제 Qt 입력·다이얼 클릭·손잡이 방향, 미리보기 취소 무변경, 적용/undo, 폼 숫자 저장 정규화 및 수정하지 않은 과거값 보존을 검사했다.
- 단일/드래그 선택 및 수정키/Esc, 편집모드 없이 심도 활성화·NULL만/전체 결과, 하이라이트·행 위치 이동, 필드 버튼 표시/Definition 갱신, 권한 차단, 저장/취소 이동 재진입 및 다른 객체 변경 보존을 검사했다.
- ZIP만 설치한 별도 QGIS 프로필에서 2개 실행 프로세스 검증 통과: 런타임 105개 모듈, classFactory/initGui, 로그인 UI·폼 생성, 동일 UI/CAD 검사, 저장 후 재시작 시 `135.125` 값과 EPSG:5186 회전식 유지, unload.
- 패키지 unittest 20개 통과. 1.4.3/1.4.4/1.4.5의 기존 SHA/크기 재현 및 새 패키지 inventory 검사. 과거 버전 파일은 hash로 입증한 원본을 runtime snapshot에 보존했다.
- 로그·manifest·감사·프로필 실행 결과는 `release/1.4.7/`에 포함한다. 패키지 감사 findings는 0이다.

## 미검증·운영 경계

운영 C26070/C26048의 실제 서버 저장/재조회, 모든 시설에 적용된 사용자 QML/SVG의 개별 기본 방향/보정은 이번 임시 레이어 검증에 포함되지 않는다. 북쪽/동쪽 규칙이 섞여 저장됐던 과거 객체를 판별하거나 일괄 복구하지 않는다. 사용자 제공 EPSG:5186과 SQL 설명을 근거로 구현했으며 실제 운영 SQL 결과 집합을 대조하지 않았다. 다른 QGIS 버전·운영 대규모 데이터의 처리시간도 미검증이다.

기존 속성값을 자동으로 변경·재계산하는 경로는 추가하지 않았다. 새 계산은 사용자가 적용한 대상만 편집 버퍼에 쓰고 서버 저장은 기존 저장 명령을 통해서만 수행한다. 운영 배포·정식 ZIP 교체·병합은 실행하지 않았다.
