# GeoFlow Connector

## 1.4.5 — 2026-10-28 (검증 후보, 미배포)

- 객체 선택 버튼의 단일/영역 모드, Shift 추가·Ctrl 해제·Esc 취소를 제공합니다.
- 기존 심도 계산을 선택 객체의 일괄계산 버튼에 연결합니다.
- 중앙 필드 설정에 따른 접속/최근접 선분 방향 계산과 검토 후 선택 적용을 제공합니다.
- 단일 객체의 지도 손잡이·숫자·다이얼 미리보기, 적용·취소·실행 취소를 제공합니다.
- 새 방향 기능은 중앙 방향 설정이 있어야 활성화됩니다. 기존 ang_dir 필드와 데이터는 생성·변환하지 않습니다.
- 운영 스타일 확인·설정 활성화·배포·설치본 교체는 별도 단계입니다.

## 1.4.4 — 2026-10-27 (검증 후보, 미배포)

- Source·측점 논리 삭제 계약을 사전에 확인하며, 계약 없는 서버에서는 삭제를 중단합니다.
- 보존 측점과 삭제 이력을 분리하고 조회 상한·실패를 명시합니다.
- 현재/원시 좌표·CRS 상세, UUID 복사, 단일·복수·Source 지도 이동과 중복 위치 비교를 제공합니다.
- 위치 확인은 생성 체크·편집 상태·서버 데이터를 변경하지 않습니다.

## 1.4.3 — 2026-10-21

- Survey Source 기반 가져오기, 코드 정규화, 시설물 매핑 및 저장 코드 처리를 개선했습니다.
- Survey와 GIS 객체 사이의 영구 관계 API 의존성을 제거했습니다.
- 공간검색 기반 생성상태·중복 방지·심도 계산을 적용하고 시설물+심도 단일 배치 저장을 유지합니다.
- 객체 선택을 현재 활성 GeoFlow 관리 레이어로 제한했습니다.
- 주변검색 기본 반경을 2.0m로 통일했습니다. 기존 프로젝트별 설정은 유지합니다.
- 심도 계산 결과와 실패 원인을 Dynamic Form에 표시하고 2.8초 후 숨깁니다.
- 기존 Dynamic Form, 온라인 저장 및 사진 기능을 유지합니다.

기존 배포 1.4.2 이후의 Connector 동작 수정에 따른 패치 버전입니다.
패키지 이름과 QGIS 지원 범위(3.28–4.99)는 변경하지 않았습니다.
