about=Thin QGIS client for GeoFlow Server. Authenticates against GeoFlow, lists only authorized GIS projects, receives the server Layer Plan, and materializes a project-scoped local GeoPackage. Version 0.5.0 introduces the development Changeset v1 path: committed QGIS edits are persisted in a local outbox, only changed UUID objects/fields and changed geometry are sent to GeoFlow, retries are idempotent, and server revision Delta updates are applied back to the local package. Whole-GeoPackage diff sync remains only as a gated fallback when Changeset support is not active. QGIS 3/Qt5 and QGIS 4/Qt6 compatibility remains enabled for development smoke testing. Production synchronization remains disabled pending separate review.
