Local change detection uses package content hashes, SQLite WAL is consolidated into a consistent backup image before upload, and the latest successful server sync wins for objects changed by multiple clients. QGIS 4 compatibility is enabled for development smoke testing. Production synchronization remains disabled pending separate review.
