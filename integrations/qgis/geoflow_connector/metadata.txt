Version 0.6.1 keeps the validated Changeset/Delta, edit-mode handling, canonical UUID behavior, and WebSocket realtime hints from 0.6.0, and fixes QGIS 4/Qt6 realtime compatibility by trying the native PyQt6 QtWebSockets module when qgis.PyQt does not re-export it. If WebSocket is unavailable or temporarily disconnected, the connector now falls back to a lightweight 1.5-second revision Delta poll so other QGIS clients still receive authoritative server changes without reopening the project. Incoming Delta is deferred while unsaved local edits exist. Whole-GeoPackage diff sync remains only as a gated fallback. Production realtime remains disabled pending a separately reviewed Redis-backed channel layer and ASGI deployment.
