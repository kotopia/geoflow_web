about=Thin QGIS client for GeoFlow Server. Authenticates against GeoFlow, lists only authorized GIS projects, receives the server Layer Plan, and materializes a project-scoped local GeoPackage. Version 0.5.1 keeps the QGIS Changeset v1 path from 0.5.0 and fixes Delta application when QGIS keeps a layer in edit mode after Save: remote Delta now reuses a clean active edit session and preserves the user's edit state instead of failing on startEditing(). Committed QGIS edits are persisted in a local outbox, only changed UUID objects/fields and changed geometry are sent to GeoFlow, retries are idempotent, and server revision Delta updates are applied back to the local package. Whole-GeoPackage diff sync remains only as a gated fallback when Changeset support is not active. Production synchronization remains disabled pending separate review.
