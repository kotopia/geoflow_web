about=Thin QGIS client for GeoFlow Server. Version 0.7.1 keeps the validated persistent Snapshot reuse, Changeset/Delta, canonical UUID behavior, QGIS 4 compatibility, signed-ticket WebSocket realtime, chunked/RTree Snapshots, and server streaming/cache work from 0.7.0. It adds safe local Snapshot lifecycle management: active/non-terminal caches become cleanup-eligible after 90 unused days, completed project caches after a 30-day grace period, while pending/outbox caches and pinned projects are never automatically removed. A configurable device cache quota is supported through QSettings and is disabled by default until explicitly set; when enabled, clean unpinned caches are evicted completed-first then by LRU. A GeoFlow menu action pins/unpins the active project cache. Whole-GeoPackage diff sync remains only as a gated fallback. Production realtime remains disabled pending a separately reviewed Redis-backed channel layer and ASGI deployment.
